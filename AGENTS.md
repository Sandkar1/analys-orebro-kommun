# Project Guidance

## Municipal Protocol Metadata

- For every municipal meeting/protocol (`sammanträde`/`protokoll`), record the correct protocol-level `Diarienummer`.
- For a specific `Sammanträde` row, use the `Diarienummer` from that exact protocol, not from an individual agenda item.
- Do not infer a protocol `Diarienummer` from nearby item titles such as `Protokoll Bom 11/2025`.
- The protocol `Diarienummer` is found on the first page of the protocol, in the top-right corner at the start of the protocol. Use that first-page value as the source of truth.

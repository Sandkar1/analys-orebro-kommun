# Project Guidance

## Municipal Protocol Metadata

- For every municipal meeting/protocol (`sammanträde`/`protokoll`), record the correct `Diarienummer`.
- Do not infer a protocol `Diarienummer` from nearby item titles such as `Protokoll Bom 11/2025`.
- The protocol `Diarienummer` is found on the first page of the protocol, usually in a corner. Use that first-page value as the source of truth.
